## VaultCrates 1.1.2 — Minecraft 26.3

**For Paper 26.3.x · Java 25 required**
Running 26.1.x or 26.2? Use `1.1.0-26.1.x` or `1.1.1-26.2` instead. On 1.21.x, stay on `1.0.1`.

### ⚠️ Before you update
- **Java 25** is now required (Paper 26.x needs it too).
- This jar only loads on Minecraft **26.3 or newer**.
- Your configs are kept — missing keys are filled in automatically.

### ✨ New
- Support for **Minecraft 26.3** (built against Paper API 26.3)
- **ItemsAdder 4.x furniture**: Display/Interaction entities and multi-part furniture (display + hitbox) are detected — clicking any part of a furniture crate opens it
- **FancyNpcs 2.x and ZNPCsPlus 2.x** NPCs can be linked: `/vc linknpc <crate> fancynpcs <name>` / `znpcsplus <id>`
- **Citizens** NPCs are linked by their NPC id, so the link survives respawns
- **VaultUnlocked** is supported for the key shop and economy crates
- **Enchantments** in rewards accept namespaced ids from enchant plugins, e.g. `"myplugin:soulbound": 1`
- The update checker only offers builds for your server's Minecraft version

### 🐛 Fixes
- **NPC crates opened without a key** — every NPC link now runs the same key, permission and economy checks as the crate itself
- `/vc linknpc` links did nothing when clicked; Citizens NPCs could not be linked at all
- Furniture crates broke when clicked (ItemsAdder picked them up); IA can no longer break or interact with a placed crate
- Shift + left-click on a furniture crate no longer deletes it silently — it shows the ID; remove with `/vc remove <id>`
- `Glow: true` added a hidden Infinity enchant — `/enchant` and anvils failed with *"cannot support that enchant"*. Glow is now a pure visual glint
- `Glow: false` now also hides the glint ItemsAdder items carry by default
- ItemsAdder `:icon:` font images were not replaced on ItemsAdder 4.x
- MMOItems and ExecutableItems rewards did not load on current versions of those plugins
- The key shop stayed disabled when the economy plugin started after VaultCrates
- Startup error (`NullPointerException`) when ItemsAdder rewards were loaded
- Purple/italic lore in the selectable-rewards GUI, shop GUI and reward footer
- "Another crate is too close" with no crate nearby (stale placements are ignored)
- `/vc reload` with a YAML error in `config.yml` reset the config to defaults — it now keeps the last valid config and prints the error
